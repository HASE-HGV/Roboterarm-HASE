# Liquid Glass — Demo

Minimal Node.js + static JSX demo showing an Apple-like liquid glass UI.

Quick start

1. Wechsel in das Verzeichnis `website`:

```bash
cd website
```

2. Abhängigkeiten installieren:

```bash
npm install
```

3. Server starten:

```bash
npm start
```

Die Seite ist dann unter `http://localhost:3000` erreichbar. Die API-Endpunkte befinden sich unter `/api/infos`.

Build

```bash
npm run build
```

Das Skript erzeugt einen `build/`-Ordner mit allen Dateien aus `public/` und einer Kopie von `server.js`.
